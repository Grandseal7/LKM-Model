# Моделирование процесса приготовления ЛКМ

## Описание
Учебное Web-приложение для моделирования изменения концентрации растворителя при смешивании смолы и растворителя, сравнения режимов и поиска режима с минимальными условными энергозатратами.

## Состав проекта
- `index.html` — структура и разделы приложения.
- `style.css` — оформление и адаптивная вёрстка.
- `app.js` — математические расчёты, графики, эксперименты и оптимизация.

## Математическая модель
Из методички:
- `G = G1 + G2`
- `Pi = (G1*C1 + G2*C2) / (G1 + G2)`
- `T = V / G`
- `C(t) = Pi + (C0 - Pi) * exp(-t/T)`

согласно методичке `C2 = 100%`.

## Допущения расширенной модели
Для демонстрации влияния скорости в приложении принято:
`Teff = T * (300 / n) / k`,
где `n` — скорость мешалки, `k` — коэффициент интенсивности. Это дополнительное допущение, а не формула из методички.

Формула условных энергозатрат для сравнения режимов:
`E = (n / 300)^3 * t * k`.
Это безразмерный условный критерий, не физическое энергопотребление в кВт·ч. 

## Ограничения
- Скорость мешалки: 100–500 об/мин.
- Время смешивания: 1–20 минут.
- Концентрации: 0–100%.
- Cmin не должна превышать Cmax.
